Privacy Policy — Receipt Bot

Last updated: 2026-11-08

Receipt Bot is a personal, non-commercial tool that runs on the developer's own computer. It is not offered to the public, and the only user is the developer.

Receipt Bot は開発者本人の PC で動く、個人用・非営利のツールです。一般には提供しておらず、利用者は開発者本人だけです。

Data accessed / アクセスするデータ

  • Gmail (read-only): purchase receipts and order confirmation emails, to record household expenses.
    Gmail（読み取りのみ）: 家計簿をつけるための購入レシート・注文確認メール
  • YouTube: creating and editing the developer's own playlists.
    YouTube: 開発者本人の再生リストの作成・編集

How data is used and stored / 使い方と保存

  • Data is processed and stored only on the developer's own computer.
    データは開発者本人の PC の中でだけ処理・保存します。
  • Data is never sold, shared with third parties, or used for advertising.
    データを販売したり、第三者に渡したり、広告に使ったりすることはありません。
  • Access tokens are kept locally and are never published.
    アクセストークンは手元にだけ保管し、公開しません。

Google API Services User Data Policy

Receipt Bot's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access / アクセスの取り消し

Access can be revoked at any time from Google Account → Third-party connections.
Google アカウントの「サードパーティ製のアプリとサービス」から、いつでも取り消せます。
